# 戴卫得 X 助手（浏览器插件）

和戴卫得AI工作台联动的浏览器插件。插件只负责在 X 页面上显示和操作，想评论、写配文、写原创都交给工作台，用工作台现有的模型（默认 GPT 6.1）、写作规则、评论文风和素材库。

## 功能
- **粉丝数**：用户名旁边直接显示粉丝数（≥1 万蓝色高亮）。数据取自 X 页面自己已经加载的内容，不额外请求，不影响账号。
- **✍︎ 助手**（每条帖子操作栏最右边）
  - 想评论：至少 3 条不同角度，中文帖回中文、英文帖回英文；可改，一键复制或填进回复框（只填，不替你发）
  - 写引用：提炼原帖，或结合账号定位和你的想法写几版配文；可填进引用框，或放进工作台今天的待发
  - 存素材：存进 `X/浏览器素材.json`，同时进博主素材库（素材只会改写成原创）
- **左下角你的头像按钮**：整理原创。勾选存过的素材、工作台信息流里的近期 AI 资讯、贴文章链接，写一两句自己的判断，生成单条或串帖草稿，可直接去发或放进工作台待发。顶部显示今日发帖、评论和粉丝进度。
- **工具栏图标**：今日进度、记录粉丝数、打开原创整理、编辑「我的表达习惯」（即 `X/我的表达习惯.md`）。

## 怎么连
工作台启动时在本机 `127.0.0.1:51888` 开一个接口，只接受浏览器插件的请求，网页本身调不到。接口代码在 `公众号写作台/浏览器助手接口.cjs`，由 `工作台接口.cjs` 加载；主插件里加了一行 `this.xKit`，把评论和写作的系统提示交给接口复用。

## 安装（Chrome）
1. Chrome 打开 `chrome://extensions`，右上角打开「开发者模式」
2. 点「加载已解压的扩展程序」，选这个文件夹：`公众号写作台/浏览器助手`
3. 改过插件代码后，在这个页面点扩展卡片上的刷新，再刷新 X 页面

## Safari / iPhone
Mac Safari 需要用 Xcode 把这个文件夹转成 Safari 扩展：`xcrun safari-web-extension-converter 公众号写作台/浏览器助手`。iPhone 上的 Safari 连不到电脑的 127.0.0.1，需要另做一个能远程访问工作台的接口，第一版先不做。
