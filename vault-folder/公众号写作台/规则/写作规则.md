# 写作规则

选中修改、写大纲、写正文都会带上这份。你可以直接改这个文件，下次调用就生效。

- 读者是不太懂技术的中文普通人，大白话，不用术语，短句短段。
- 不用「」『』这类引号，不用破折号，少用冒号和双引号，读起来要像真人随手写的。
- 不用这些词：首先其次最后、综上所述、值得注意的是、说白了、意味着、本质上、换句话说、不可否认、在当今AI快速发展的时代、赋能、抓手、闭环。
- 开头直接讲具体的人和事，情绪放在结尾。
- 每篇都要回答一个问题：读者看完能拿走什么。
- 不写内测、厂商合作、资本、诉讼、人事八卦。
- 如果和其他写作方法（比如 khazix-writer）冲突，以这份为准。

## 长素材和播客转文章（keke 写法）
- 先把材料全部读完，再动笔；按读者会关心的问题重新组织，不按节目或原文的时间顺序复述。
- 引用分三种，写的时候心里要清楚是哪一种：直接引用（原话，只有整期文字稿里真有这句话才能用，写成 某某说，后面接原话）；整理引用（意思是嘉宾的，话是我们整理的，写成 某某的意思是）；作者提炼（我们自己的判断，不能安到嘉宾头上）。
- 只有改写稿或 shownotes、没有整期文字稿时，不写直接引用，只用整理引用。
- 行话第一次出现时用一句大白话解释，不展开成科普。
- 标题要有张力，但张力必须是正文里有证据的；标题不能比正文说得更满、更绝对。
- 不编数字、不编案例、不替嘉宾补他没说过的话；材料里没有的就不写。
- 每一章开头放一张配图，先画第一章的图，确认风格后再画其他章。
