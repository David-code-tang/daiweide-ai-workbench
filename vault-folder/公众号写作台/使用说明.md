# 戴卫得AI工作台 使用说明

打开方式：Home 主页「常用入口」里的「公众号写作台」，左边栏的报纸图标，或命令面板里的「公众号写作台：打开写作台」。

第一次打开会有新手指引，一步一步讲每个区域。想再看，在「规则和 Skill」页点「新手指引」，或命令面板运行「公众号写作台：新手指引」。

## 每天的流程
1. 早上 7 点以后第一次打开 Obsidian，会自动刷新信息流并出今天的选题（Obsidian 开着时每 15 分钟检查一次，信息流每 6 小时自动刷新）。
2. 在「今天」里点开选题看详情，标题候选点一下就换成那个标题，满意就点「选这篇」。
3. 右边会新建一篇稿件，大纲一边生成一边写进去。看完满意，命令面板运行「按大纲写正文」。
4. 选中任何一段，点浮出的「✦ AI 修改」或按 Cmd+Shift+K：
   - 直接输入想法，或点 改写、扩写、缩短、换个开头、出标题。
   - 模型可以随时换；勾上「对比」，两个模型同时改，并排挑一个。
   - 结果标红标绿，点「接受」才替换，Cmd+Z 可以撤回。
   - 「配图」用 GPT 画这一段的插图，满意就插入。
5. 命令面板：「生成封面」（自动裁成 2.35:1）、「复制为公众号格式」（直接粘到公众号编辑器）、「打开这篇的白板」。
6. 发完在「本周」里点「发完了」。

## 改规则
- 规则/写作规则.md：改稿、大纲、正文都会用，直接改就生效。
- 规则/蒸馏规则总表.md：出选题用。
- skills 文件夹：放自己的 Skill（一个文件夹一个 Skill，里面放 SKILL.md）。

## 设置
插件设置里可以：检测 Claude Code 和 Codex、换每个动作的默认模型、改禁用词、开关自动任务、改出选题的时间和数量。

## 注意
- 用的是你本机 Claude Code 和 Codex 的订阅登录，不用 API key，会占用订阅额度。登录过期时，在终端运行 claude 或 codex 重新登录。
- 正文里需要你亲身经历的地方会写【你来补】，复制到公众号前插件会提醒还有几处没补。
- 图片要在公众号编辑器里手动上传，复制时位置已经标出。

## X 发帖台

写作台顶上的「X 发帖台」，或者命令面板里的「打开 X 发帖台」。

- 今日帖子：每天早上 7 点以后打开 Obsidian，会自动准备好 1 篇长文、2 条串、17 条单条（大多是带原帖链接的引用转发），每条后台自动配图。大字是你本地时间，下面小字是北京时间，只排在你能发的时间里（设置里可改，默认 08:00 到 23:30）。
- 去发：配图先复制到剪贴板，再打开 X 的发帖框，文字和原帖链接都填好了。在发帖框里按 Cmd+V 贴图，检查后自己点发送，回来点「已发」。不想发就「跳过」，会从候补里补一条。
- 改：正文可以直接改，或点 换个写法、更短、更有冲击力、更好收藏，或在输入框里自己说怎么改。右上角绿勾红叉是自动检查（五件套、可见、可点、可算）。
- 串：先点「去发第 1 条」，在 X 里点「+」，再回来点「复制第 2 条」粘贴，依次往下。
- 长文：点「写长文」生成正文，点「复制长文」后粘进 X 的文章编辑器，标题单独填。
- 评论雷达：大约每 2 小时找一次最近的 AI 热帖，每条有推荐回复和两个备选（点一下换上去）。「去回复」打开回复框，你自己点发送。也可以贴一条帖子链接让它写回复。
- 一键加工：贴链接或内容，或拖图片和视频进来，选做成什么，几十秒出稿，点「加入今天」排进时间表。视频需要电脑上装了 ffmpeg（终端运行 brew install ffmpeg）。
- 复盘：把自己主页导出的 CSV 导进来，看哪类、哪个时间、多长的帖子收藏最高。
- 规则：规则/X写作规则.md，改了马上生效。配图 Skill 放进 skills 文件夹后在插件设置里选。

## 10-11 晚更新

- 内容配比：微信公众号页上方统计最近 7 天选了哪类文章。新闻解读 2 篇以上、某类占到四成、或者连着两天同一类，会黄色提醒该换领域，并给出建议类型。出选题时也自动照这个来，卡片上会标最近写多了、推荐换这类。

- 信息流每条下面有两个按钮：＋ 公众号选题（同上），＋ 做成 X 帖子（打开一键加工，链接已填好）。
- Skill 收集：自动扫描电脑上所有 Skill（工作台、Claude Code、Codex、Agents、Claude Code 插件），用最便宜的 GPT 分类。新 Skill 点收进一个 Skill 文件夹；分错了在卡片下拉框里改。分类存在 规则/Skill分类.json。

## 10-12 凌晨更新

### 写作画布（边看边改）
- 打开方式：微信公众号页「已选」那行的「写作画布」按钮，或在任意稿件里用命令「打开写作画布」。选这篇、播客转文章之后会自动打开。
- 左边是稿件本身：图片视频直接显示，直接打字改，图片视频拖进去就行，划词照样用 AI 修改。
- 右边是画布面板：
  - 大纲和章节：正文按 ## 小标题分节（没有小标题就按段落分块），每节有 重写 / 扩写 / 精简 / 更口语 / 配图；点节标题跳到那里。没有小标题时可以点「让 AI 加小标题」，只插标题不改正文。
  - 和 AI 改稿：选范围（选中的文字 / 光标所在的一节 / 整篇），写要求，点「改」直接改进稿件，点「问」只回答不动稿件。
  - 版本：每次 AI 改之前自动存一版，也能手动存；可以对比、恢复。不满意也可以直接 Cmd+Z。
  - 顶部按钮：按大纲写正文 / 重写全文、生成封面、推到草稿箱、插入图片视频、在光标处配图。

### 推到公众号草稿箱
- 用的是你自己的暖石排版工作台（创作/90-工具/暖石排版工作台），凭证由它管，插件不碰。
- 推之前自动检查：章节小标题、封面、还有没有没填的【你来补】（有就不让推），再试排一遍，逐段核对正文、图片数、封面素材有没有混进正文。全部通过才能点推送。
- 推完稿件状态改成「已推草稿」，记下草稿 id。群发自己去 mp.weixin.qq.com 点。
- 如果提示 IP 白名单或凭证过期，按弹窗里的提示处理。

### 播客 / 长素材转文章
- 入口：信息流里播客条目的「＋ 播客转文章」、微信公众号页链接栏旁的「播客/长素材转文章」、命令「播客或长素材转文章」。小宇宙链接、文章链接、一大段文字都行。
- 材料：乔木 RSS 的改写稿（只有 42章经、半拿铁、张小珺、晚点聊、Next Token 这几档有）＋ 小宇宙 shownotes。小宇宙官方文字稿要登录 App，拿不到。
- 想要逐字稿：终端运行 pip install mlx-whisper，重启 Obsidian，弹窗里点「先转整期文字稿」。
- 写法用 keke 的方法（已加进 规则/写作规则.md）：按读者关心的问题重新组织；没有逐字稿就不写原话引用；标题不比正文说得更满。
- 完整素材存在 公众号写作台/素材/，稿件里的「素材」字段指向它，按大纲写正文时会一起交给模型。

### 一键加工不再交白卷
- 模型偶尔会返回空正文。现在会先从别的字段找，找不到自动换一个模型重写，界面会提示。原始输出存在 X/媒体/最近一次加工原始输出.txt。

## 10-17 新版「微信公众号」页（内容工作台）

参考 Gary（曹淦）开源的 content-workbench 重做，界面和底层都换成了它那套，旧版写作台页面已去掉（每天 7 点自动出选题照旧，会同步进来）。

- 今天：随手记一笔（或录音、传音频，本机转写），它会自动提炼几个选题；每个选题卡片上点「写成公众号」或「写成 X」，直接进稿件页起草。
- 信息流里打开一篇文章，点「拿来写公众号」，全文会存成写作素材，一两分钟后选题里出现从这篇提炼的选题。
- 稿件页：中间是正文（图片直接显示，顶上一排排版按钮）；右边一栏：预览（公众号排出来什么样）、批注、封面配图、小红书、视频、备注、文风、记录。
- 批注改稿：选中一段写批注，或者在右边写对全文的意见，攒几条点「按批注修改」，AI 一次改完、每条回复改了什么；改完能「看改动」，不满意「撤回这一轮」。AI 需要你亲自补的地方也挂成批注，不塞进正文。
- 改稿习惯：你在 AI 底稿上的修改会被记下来，攒够 3 轮自动总结成你的改稿习惯，之后起稿照着来。在左边「改稿习惯」里可以看、改、关。
- 推到草稿箱：先在左下「设置」里填公众号的 AppID 和 AppSecret，并把这台电脑的出口 IP 加进公众号后台白名单。推之前会弹一张清单（标题、几张图、排版怎么转），确认后才推，只进草稿箱，不发表。
- 留档：每篇稿子停笔一分半钟后自动存一份到 公众号写作台/稿件/工作台（同名 Markdown，图片在 附件 里）。在 Obsidian 里改过的不会被覆盖，会停下来等你决定。
- 拖动和删除：素材、选题、稿件都可以按住拖动调顺序；删除先进左边「回收站」，删完提示里点「撤销」立刻找回，也可以去回收站「恢复」。回收站里彻底删除的，旧选题同步不会再带回来。
- 模型：起稿、提炼、改稿都用工作台插件里的模型（默认 GPT 6.1），不另外调 Claude。
- 数据在插件目录 cw-data 里（不进坚果云）。Obsidian 要开着它才能用；也可以点右上角「在浏览器里打开」，在 Chrome 里用。

## 10-17 晚：每天自动出公众号稿

- 「今天」页最上面的「今日自动稿」：每天 7:30 以后（早上第一次开 Obsidian、旧系统出完选题后）自动从待挑选题里打分挑 2 篇（可改 1–3 篇），写成成稿放进「稿件」。也可以点「现在就出」。
- 每篇的流水线：选题打分（热度×0.3 + 相关度×0.4 + 切入价值×0.3）→ 任务书和主张清单（找不到来源的说法不进正文）→ 按任务书写 → 编辑五项审稿，不过就自动改，最多两轮 → 本地文风检查 → 去 AI 腔润色（只改表达不加事实）→ 12 个标题打分出 5 个候选 → 3–5 张逻辑图插进正文 → 三张封面（公众号 2.35:1 标题压在分享安全区、方形 1:1、X 长文 5:2）。
- 每篇右边「备注」里有：选题打分、5 个标题候选、审稿分和问题、要核实的事、被拦下的无来源说法、文风提示。
- 文风档案：规则/我的文风档案.md，和写作规则一起用，改了下一篇就生效。
- 推草稿箱：没填 AppID 时，「推到草稿箱」会交给 Chrome 扩展，用你 Chrome 里登录着的公众号后台上传图片、存草稿（只存草稿，不发表）。Chrome 要开着、公众号后台要登录着；一两分钟内完成，结果在稿件右边「记录」里。
